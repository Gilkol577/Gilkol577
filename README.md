I am a software developer focused on building practical, reliable, and thoughtfully designed digital products. My work combines software engineering fundamentals with AI-assisted development, automation, backend systems, and modern user experiences.

I enjoy moving across the full product lifecycle—from understanding a problem and designing the architecture to implementing, testing, refining, and shipping the result.
